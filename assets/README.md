# Assets

This directory contains the visual branding and icons for the PaperPilot Add-in.

## Visual Assets

- **`paperpilot.png`**: High-resolution source logo.
- **`paperpilot.ico`**: Windows application icon (used for desktop integration).
- **`icon-16.png`, `icon-32.png`, `icon-64.png`, `icon-80.png`**: Manifest-compliant icons generated from the source logo.

## Requirement

Microsoft Office Add-ins require specific icon sizes to be defined in the `manifest.xml`. These icons are displayed in:
1. The **Insert → Add-ins** dialog.
2. The **Home** ribbon tab.
3. The **Taskpane** header (optional).
4. Context menus.

For more information on icon generation, see **[ICON_GENERATION_INSTRUCTIONS.md](../ICON_GENERATION_INSTRUCTIONS.md)**.
